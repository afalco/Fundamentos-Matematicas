\section{Definir}

\begin{frame}{Definir}
\begin{block}{Qué hace una definición}
\begin{itemize}
  \item Una definición fija el significado de un término o símbolo.
  \item No se demuestra: se acepta como acuerdo de significado.
  \item Debe indicar contexto, objetos implicados y condiciones.
\end{itemize}
\end{block}
\end{frame}

\begin{frame}{Definir}
\begin{block}{Ejemplo: número par}
\begin{itemize}
  \item Sea \(n\in\mathbb{Z}\).
  \item Diremos que \(n\) es par si existe \(k\in\mathbb{Z}\) tal que \(n=2k\).
  \item La definición introduce una propiedad mediante una existencia.
\end{itemize}
\end{block}
\end{frame}

\begin{frame}{Definir}
\begin{block}{Definiciones defectuosas}
\begin{itemize}
  \item Una definición circular usa el término que pretende definir.
  \item Una definición incompleta no fija el conjunto de trabajo.
  \item Una definición ambigua no permite decidir casos básicos.
\end{itemize}
\end{block}
\end{frame}

\section{Afirmar y probar}

\begin{frame}{Afirmar y probar}
\begin{block}{Enunciado matemático}
\begin{itemize}
  \item Un enunciado es una afirmación con valor de verdad dentro de un contexto.
  \item ``Calcula \(2+3\)'' no es un enunciado: es una orden.
  \item ``Para todo \(n\in\mathbb{N}\), \(n+1>n\)'' sí es un enunciado.
\end{itemize}
\end{block}
\end{frame}

\begin{frame}{Afirmar y probar}
\begin{block}{Ejemplos y contraejemplos}
\begin{itemize}
  \item Un ejemplo muestra un objeto que satisface una definición o propiedad.
  \item Un contraejemplo muestra que una afirmación universal es falsa.
  \item Muchos ejemplos no sustituyen una demostración general.
\end{itemize}
\end{block}
\end{frame}

\begin{frame}{Afirmar y probar}
\begin{block}{Calcular no es demostrar}
\begin{itemize}
  \item Calcular produce un valor o transforma una expresión.
  \item Demostrar justifica por qué una afirmación es verdadera en todos los casos indicados.
  \item Una solución universitaria debe dejar claras hipótesis, conclusión y método.
\end{itemize}
\end{block}
\end{frame}

\section{Plantilla de demostración}

\begin{frame}{Plantilla de demostración}
\begin{block}{Estructura mínima}
\begin{itemize}
  \item Hipótesis: qué se supone.
  \item Objetivo: qué se quiere demostrar.
  \item Argumento: pasos justificados.
  \item Cierre: se indica que se ha probado la afirmación deseada.
\end{itemize}
\end{block}
\end{frame}

\section{Profundización}

\begin{frame}{Profundización}
\begin{block}{Cómo evaluar una definición}
\begin{itemize}
  \item Debe especificar el conjunto o contexto de trabajo.
  \item Debe introducir todos los símbolos relevantes.
  \item Debe permitir distinguir ejemplos de no ejemplos.
\end{itemize}
\end{block}
\end{frame}

\begin{frame}{Profundización}
\begin{block}{Ejemplo y contraejemplo}
\begin{itemize}
  \item Definición: \(n\in\mathbb{Z}\) es par si existe \(k\in\mathbb{Z}\) tal que \(n=2k\).
  \item Ejemplo: \(8\) es par porque \(8=2\cdot 4\).
  \item Contraejemplo: \(7\) no es par, porque no existe entero \(k\) con \(7=2k\).
\end{itemize}
\end{block}
\end{frame}

\begin{frame}{Profundización}
\begin{block}{Checklist de demostración}
\begin{itemize}
  \item Declaro las hipótesis.
  \item Declaro lo que quiero probar.
  \item Uso definiciones ya introducidas.
  \item Cierro indicando que la conclusión ha quedado probada.
\end{itemize}
\end{block}
\end{frame}

\begin{frame}{Cierre}
\begin{itemize}
  \item Una definición introduce significado.
  \item Un enunciado afirma algo verdadero o falso.
  \item Una demostración no verifica casos: justifica el caso general.
\end{itemize}
\end{frame}
