# Fundamentos de las Matemáticas I y II

Apuntes en LaTeX y PDF de las asignaturas **Fundamentos de las Matemáticas I** y **Fundamentos de las Matemáticas II** de Ingeniería Matemática.

## Estructura del repositorio

- **FMI**: Apuntes de Fundamentos de las Matemáticas I
- **FMII**: Apuntes de Fundamentos de las Matemáticas II
- **Fundamentos-Matematicas**: Material adicional
- **Manual**: Manuales y guías

## Formato de los archivos

- `.tex`: Archivos fuente en LaTeX
- `.pdf`: Versiones compiladas en PDF
